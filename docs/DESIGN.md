# 设计说明

本插件是 DeepSeek Harness 的浏览器端交互层，目标是提供一套克制、键盘优先、与宿主原生能力不冲突的界面增强。所有能力都建立在宿主公开的插槽（Slot）和服务（Service）之上，不修改宿主文件，也不替换应用根节点。

## 设计原则

1. **只在官方座位渲染**：主题走 `theme.overrideTokens` 令牌层；运行条、面板、朗读、页脚、设置分别注册到 `conversation.input.dock`、`shell.overlay`、`conversation.chat.assistant-actions`、`conversation.chat.turnTail`、`settings.section` 等公开插槽。对话流、工具卡、审批、输入框和队列仍由宿主拥有。
2. **可逆**：主题是覆盖层，关闭开关即移除；所有组件随插件上下文销毁；卸载后不留下全局样式或定时器。
3. **降级而不是崩溃**：缺服务、缺槽位、缺浏览器能力时，对应控件隐藏或退化为无操作，其余功能不受影响。
4. **键盘优先，但不抢宿主键位**：只接管空输入框里的 `↑/↓`、`?`，以及明确的 `Alt+B`、`Alt+N`、`Ctrl+K`；所有监听都先检查 `defaultPrevented`、输入法与弹层状态。
5. **无外部品牌资产**：状态星是 Unicode 字符 `✻`（U+273B），按钮图标为内联 SVG，不包含第三方图标、字体或截图。

## 视觉与主题

- 两套完整令牌：中性炭黑（暗）与中性浅灰（亮），由 `theme` 服务按当前亮暗偏好选择。
- 品牌色为陶土橙 `#d77757`，用户消息块、输入区、选中态、success/error/warning 与 diff 颜色都经过统一整理；只覆盖 `--dsw-*` 令牌，不写宿主选择器。
- 运行状态星的六帧脉冲、回合页脚的完成词、动词池都是插件自己的展示层设计。

## 交互层

| 能力 | 落点 | 说明 |
| --- | --- | --- |
| 运行状态条 | `conversation.input.dock` | 空闲提示发送/换行/历史/命令/文件/面板/快捷键；运行时显示动词、脉冲星、工具时长与中断入口。 |
| 提示词历史 | 运行条 keydown + 面板 | 空输入框 `↑` 召回、`↓` 回到更新/恢复草稿；面板提供「历史提示」分组并可回填。 |
| 快捷键一览 | `shell.overlay` | 空输入框按 `?` 打开，输入/导航/界面三组。 |
| 左侧边栏折叠 | `layout.toggleSidebar` | 运行条 `«`、`Alt+B` 与面板动作三个入口。 |
| 插件图标折叠 | `sidebar.panellist.actions` | 在侧边栏「更多」菜单中逐项显示/隐藏、一键收起/展开插件图标。 |
| 命令面板 | `shell.overlay` | `Ctrl+K` 模糊搜索、分组、键盘导航；动作涵盖模式/主题/组件开关、侧边栏、插件图标、快捷键、中断与新建会话。 |
| 聊天记录搜索 | `sessions.search` + 面板 | 输入两个以上字符时防抖搜索宿主全文索引，结果进入「聊天记录」分组，回车打开对应会话；索引未启用时安静缺席。 |
| 助手回复朗读 | `conversation.chat.assistant-actions` | 在已定稿助手消息的操作条中朗读正文，支持停止、语言跟随与长文分块。 |
| 完成提示音 | 运行态迁移 + 设置 | 回合结束时可选播放两声轻提示；默认关闭，可试听、可面板开关。 |
| 新建会话快捷键 | `uiWorkspace.startSession` | `Alt+N` 打开空白会话。 |
| 回合页脚 | `conversation.chat.turnTail` | 完成后显示完成词与用时，兼容 list 与旧版 chain 槽。 |
| 设置页 | `settings.section` | 总开关、主题、状态条/页脚/动效/提示音、试听、快捷键、恢复默认、关于。 |

## 动效与可访问性

状态星逐帧脉冲、面板入场和控件过渡都遵循 `prefers-reduced-motion` 与插件内的「动效」开关。面板使用 `role="dialog"`、`aria-modal`，开关使用 `role="switch"` 与 `aria-checked`，分段控件使用 `aria-pressed`，所有按钮保留可见焦点环和可读标签。
